# Jumanazar Abdirasulov - Professional Portfolio

Modern, high-performance portfolio showcasing Data Science and Machine Learning projects.

## 🚀 Key Features
- **Glassmorphism UI:** Modern dark mode aesthetic with emerald green accents.
- **Interactive Experience:** Smooth scroll, scroll-reveal animations, and responsive design.
- **Integrated Projects:** Direct links to live demos and deep-dive project files.

## 📂 Project Structure
- `index.html`: Main portfolio entry point.
- `css/style.css`: Professional design system and styles.
- `js/main.js`: Animation logic and UI interactions.
- `projects/`: Contains deep-dive projects (e.g., Islamic Bank Risk Analysis).
- `assets/`: Image assets and visual elements.

## 🛠 Tech Stack
- HTML5 / CSS3 (Modern Flex/Grid)
- JavaScript (Vanilla, ES6+)
- FontAwesome / Google Fonts
